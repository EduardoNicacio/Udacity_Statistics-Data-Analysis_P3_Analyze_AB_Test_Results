## Code Quality

### Criteria

Functionality of code

### Submission Requirements

Use of Good Coding Practices

### Criteria

Correct Interpretation of Results

### Submission Requirements

The interpretation of all results from different analyses is correct and includes both statistical reasoning and practical reasoning.

Correct Values for All Statistical Results

### Submission Requirements

All statistical numeric values/results are calculated correctly.

**Tip**: Students can optionally attempt the classroom quizzes to ensure they are calculating the right value in many cases.

### Criteria

Appropriate Presentation Slideshow

### Submission Requirements

A slide show is included. Each slide has been update appropriately, as outlined in the template slide show. This includes both updating the results/tables and, where relevant, including an accurate interpretation of those results.

If you worked on your local machine, save the **completed** presentation deck containing your results as a **PDF** file. And combine it with the **completed** Jupyter Notebook (**.ipynb** file) containing your code as a **zip** file.
